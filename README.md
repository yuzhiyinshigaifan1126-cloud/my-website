# 邱惠娟 / Creative Producer

这是可直接部署到 GitHub Pages 的完整静态网页版本。

## 目录

- `index.html`：网页入口
- `css/styles.css`：完整构建后的样式文件
- `js/main.js`：完整构建后的 React 运行代码与交互逻辑
- `assets/`：作品图片、头像和首页背景图

## 部署到 GitHub Pages

1. 将 `github-pages-static` 文件夹中的全部内容上传到 GitHub 仓库根目录。
2. 打开仓库的 `Settings → Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 选择需要发布的分支和 `/ (root)` 目录并保存。

本版本已经使用相对资源路径，部署到 GitHub Pages 的项目子路径也可以正常加载图片、CSS 和 JS。
